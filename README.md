# Brainwave Knowledge Hub – AI-Powered Quiz App

**An interactive AI-driven quiz platform that dynamically generates personalized quizzes based on user-selected topics and difficulty levels.**

---

## 🚀 Features

- Generate **10-question quizzes** on any topic with selectable difficulty (Easy, Medium, Advanced).  
- **AI-generated explanations** for correct answers using Google Gemini API.  
- Real-time **answer validation** with color-coded feedback.  
- **Timer-based quiz mechanics** and visual progress indicators.  
- Track **high scores** locally (extendable to Firebase for persistence).  
- Fully **responsive and animated UI/UX** with Tailwind CSS and Framer Motion.  
- Anonymous authentication with **Firebase Auth**.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, JavaScript  
- **Styling & Animations:** Tailwind CSS, Framer Motion  
- **AI Integration:** Google Gemini AI API  
- **Backend/Auth:** Firebase Auth (optional Firestore integration for storing scores)
